# homebrew-tap

Homebrew casks for [jonhadfield](https://github.com/jonhadfield)'s tools.

```sh
brew install --cask jonhadfield/tap/subnets
```

| Cask | Description |
| ---- | ----------- |
| [git-crux](https://github.com/jonhadfield/git-crux) | AI commit-message reviewer |
| [ip-fetcher](https://github.com/jonhadfield/ip-fetcher) | Fetch IP ranges from popular sources |
| [orange-cli](https://github.com/jonhadfield/orange) | Terminal reader for Hacker News (`orange`) |
| [sn-cli](https://github.com/jonhadfield/sn-cli) | Standard Notes CLI |
| [sn-dotfiles](https://github.com/jonhadfield/sn-dotfiles) | Manage dotfiles with Standard Notes |
| [subnets](https://github.com/jonhadfield/subnets) | IPv4/IPv6 subnet calculator CLI |
| [subtocheck](https://github.com/jonhadfield/subtocheck) | Check FQDNs for subdomain takeover |
